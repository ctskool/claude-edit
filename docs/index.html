What happens

New format · /claude-edit-versus

Raw vs Claude

Film one 16:9 take and ask for edits out loud: "give me captions", "make it warmer", "put a big title behind my head", "pull the camera closer", "bring in some music". Claude finds each request in the transcript and lands that edit on the word you name it, in the top panel. The bottom panel is the same take with only the dead space cut. An edit log fills in as you go, every change gets a sound, and the music bed is synthesised in code (nothing to license).

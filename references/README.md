# references/

Measure your own reference reels here. `HOW.md` walks the four layers: what you noticed, what the numbers say, the rules you keep, and how they reach an edit. `tools/reference.py measure` does the measuring.

Nothing from other creators ships with this repo. Each reel you add gets its own folder, `references/<slug>/`, which git ignores: keep the clips, frames and transcripts on your own machine.
